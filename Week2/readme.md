# Week 2 – Data Sourcing, Import and Transformation

## Objective
To collect construction datasets and prepare them for analysis using Power BI and Power Query.

## Datasets Used
1. Project Risk Dataset
2. Earned Value Metrics Dataset
3. Project Delay and Cost Overrun Dataset
4. Construction MEP Time-Motion Dataset

## Tools Used
- Power BI Desktop
- Power Query
- Microsoft Excel
- CSV

## Activities
- Imported datasets into Power BI.
- Checked missing values and duplicate records.
- Corrected data types.
- Cleaned and transformed data.
- Used Column Quality and Column Distribution for data profiling.

## Deliverables
- Power BI project file
- Week 2 documentation
- Data cleaning screenshots

## Status
Data sourcing, importing and transformation activities completed. Dashboard development is planned for a later phase.
